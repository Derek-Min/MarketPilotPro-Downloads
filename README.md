## Install
1. Download the installer ZIP above.
2. Open your Downloads folder, right-click the ZIP and select Extract All.
3. Open the extracted folder and run MarketPilotPro-0.9.0-rc.1-win-x64-Setup.exe.
4. Follow Setup, then open MarketPilot Pro from the Start menu.
5. Sign in with an administrator-provided account.
Requires Windows 10 version 2004 or later / Windows 11, x64. The .NET runtime is included. Internet is required at every sign-in. Downloading does not create an account; request your account privately from the administrator.
